O [texto do post](LINKEDIN_POST.md) apresenta a proposta, o problema resolvido e as contribuições do Axo. O projeto está disponível em [Pedroltz/AxoImageStudio](https://github.com/Pedroltz/AxoImageStudio).

## Próxima demonstração

Para apresentar uma geração realizada pelo Axo, substitua uma arte conceitual pelo arquivo original gerado no Colab e inclua os parâmetros utilizados. O [guia de demonstrações](DEMOS.md) lista o que registrar.

A publicação no LinkedIn é feita pelo proprietário do perfil. Este material entrega o texto e os arquivos; nenhum post foi enviado automaticamente.
